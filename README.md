# Student Record Search System using BST

A C-language mini project implementing a **Binary Search Tree (BST)** 
to manage student records (Enrolment ID, Name, Department).

## Features
- Insert student (duplicate IDs rejected)
- Search by Enrolment ID
- Delete node (leaf / one-child / two-children)
- Inorder, Preorder, Postorder traversals
- Load 10 sample records
- Complexity comparison: balanced vs skewed BST
- Comparison counter for runtime analysis
